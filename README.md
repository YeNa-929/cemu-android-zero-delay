# Cemu Android · Zero Delay

**[안드로이드용 zd2 APK 다운로드](https://github.com/YeNa-929/cemu-android-zero-delay/releases/download/v0.5-zd2/Cemu-0.5-ZeroDelay-zd2.apk)**

SSimco Cemu 0.5 기반 비공식 ARM64 버전입니다. 구형 Zero Delay 보드가 키보드 이벤트로 보내는 버튼을 수동 매핑과 게임 입력에서 처리합니다. 사용자의 안드로이드 기기에서 zd2 실행과 보드 버튼 인식을 확인했습니다.

안드로이드에서 위 APK를 내려받아 설치하세요. 기존 Cemu와 별도로 설치되며, zd1 사용자는 업데이트로 설치할 수 있습니다. 컨트롤러 설정에서 A와 B를 선택하고 각각 원하는 물리 버튼을 눌러 지정하세요.

[최신 릴리스](https://github.com/YeNa-929/cemu-android-zero-delay/releases/latest) · [버튼 입력 소스 패치](https://github.com/YeNa-929/cemu-android-zero-delay/releases/download/v0.5-zd1/cemu-zero-delay-buttons.patch)

## 철권 태그 토너먼트 2 그래픽 팩

[1024×600 그래픽 팩 다운로드](https://github.com/YeNa-929/cemu-android-zero-delay/releases/download/v0.5-zd2/TekkenTagTournament2-1024x600.zip)

Cemu를 종료한 뒤 ZIP의 `rules.txt`를 기존 `TekkenTagTournament2_Resolution` 폴더에 덮어쓰세요. Cemu를 다시 열고 그래픽 팩 → Tekken Tag Tournament 2 → Graphics → Resolution에서 `1024x600`을 선택하세요. 실기기에서 게임 화면은 아직 검증 전입니다.
